Subject: Pedagogical Analysis for Slide Design

Context:

The lesson covers the following topics: {topics}

The complete handout for this lesson is provided below:
{handout}

Module Structure:
{module_structure}

Task:
Analyze each topic in this lesson from a pedagogical perspective to inform how we should present it in slides.

For each topic, provide:

1. **Complexity Level**: Rate as Simple, Medium, or Complex
   - Consider: mathematical depth, prerequisite knowledge, conceptual difficulty

2. **Teaching Approach**: Identify the most effective teaching method(s):
   - **Mathematical derivation**: Requires equations, proofs, formal notation
   - **Visual intuition**: Benefits from diagrams, progressive visual build-up
   - **Practical examples**: Needs code, real-world cases, demonstrations
   - **Conceptual overview**: Definitions, high-level understanding, framework
   - **Step-by-step process**: Sequential explanation building from simple to complex

3. **Cognitive Load**: Estimate the mental effort required:
   - Light: Simple concept, easy to grasp
   - Medium: Requires attention and some prior knowledge
   - Heavy: Dense material, needs careful explanation and time

4. **Key Concepts**: List 2-4 crucial concepts that MUST be emphasized

5. **Visual Requirements**: What types of visuals would help?
   - Diagrams (geometry, architecture, flowcharts)
   - Equations and mathematical notation
   - Images/photos (examples, real-world scenarios)
   - Animations or progressive reveals
   - Code snippets
   - Tables or comparison charts

6. **Prerequisites**: What must students already understand?

7. **Teaching Notes**: Any special considerations for presenting this topic effectively

Output Format:
Organize your analysis by topic, using clear markdown formatting. Be specific and actionable—this analysis will directly inform slide allocation and design decisions.

Example structure:
```markdown
## Topic 1: [Topic Name]

**Complexity**: Medium
**Teaching Approach**: Visual intuition + Mathematical foundation
**Cognitive Load**: Medium-Heavy
**Key Concepts**:
- Concept A

- Concept C

- Geometric diagrams showing camera setup
- Step-by-step visual build-up of epipolar geometry
- Mathematical equations for formal relationships

**Prerequisites**:
- Camera projection model
- Basic linear algebra

**Teaching Notes**:
Start with intuitive geometric explanation before introducing formal mathematics.
Use progressive reveal to build complexity gradually.
```
